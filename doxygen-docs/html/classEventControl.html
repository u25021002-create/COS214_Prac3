Detailed Description

Concrete Subject: the event control centre that raises notices.

EventControl is deliberately not an EventComponent. It is not part of the containment tree; it is the coordinator that broadcasts into it. It knows only Observer and EventNotice, so a new kind of unit can be added to the event without changing this class.
