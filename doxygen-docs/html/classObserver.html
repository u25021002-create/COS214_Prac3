Detailed Description

Abstract Observer in the Observer pattern.

An Observer is told that something has changed and is handed the notice that describes it, because EventFlow pushes rather than pulls. Each concrete observer decides for itself how to react, so no subject ever needs to know which concrete classes are listening to it.

An Observer is never owned by the Subject it registers with; see Subject.
