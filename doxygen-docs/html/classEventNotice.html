Detailed Description

The information a Subject pushes to its Observers.

EventFlow uses a push Observer, so the complete notice travels with the update(...) call. EventNotice is an immutable value object: it is created by the subject, passed by const reference, and copied by value if a receiver needs to keep it. No observer ever holds a pointer into a notice.
